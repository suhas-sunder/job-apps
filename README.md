# Job Applications

Obsidian-compatible job application tracker.

This repository is intended to be the durable source of truth for job-search activity. Each application gets its own Markdown note with standardized YAML frontmatter, while `Dashboard.md` provides the quick visual overview.

## Structure

- `Dashboard.md` — current job-search overview and active pipeline
- `Applications/` — one note per job application
- `Templates/Application.md` — template for new applications
- `System/Tracker Instructions.md` — rules for maintaining the vault consistently
- `System/Status Definitions.md` — canonical application statuses
- `System/Update Log.md` — chronological audit trail of material changes

## Obsidian

Clone this repository and open the repository folder as an Obsidian vault. No community plugins are required for the core tracker.

The files are deliberately plain Markdown so they remain readable in GitHub, Obsidian, and other editors.
